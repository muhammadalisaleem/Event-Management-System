# EMS - Event Management System

*Discover. Register. Attend.*

An event management app built with React and Redux Toolkit. Events are loaded from the Ticketmaster Discovery API.

## Features

- Register, login and logout (saved in local storage)
- Browse, search and filter upcoming events
- Event categories and event details
- Register for events and cancel registration
- My Events page with upcoming and completed events

## Tech

React (Vite), Redux Toolkit, React Router, Ticketmaster Discovery API
